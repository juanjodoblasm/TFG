# MODELIZACIÓN DE DATOS CON ESTRUCTURA MIXTA: UN ANÁLISIS DEL CONTEO DE MUERTES EN EUROPA

Este repositorio contiene el código desarrollado para la parte práctica del Trabajo de Fin de Grado (TFG) en Matemáticas titulado *“Modelización de datos con estructura mixta: un análisis del conteo de muertes en Europa”*. El objetivo principal del trabajo es diseñar e implementar un modelo binomial negativo mixto para el análisis de datos de conteo sobredispersos y composicionales con estructura jerárquica, aplicado al estudio de la mortalidad en Europa.

El código implementa los procedimientos estadísticos y las visualizaciones utilizadas para la modelización y análisis de los datos.

---

## 📖 Requisitos previos

Para una mejor comprensión del contenido y el código aquí incluidos, se recomienda la lectura de los capítulos 2 y 3 del documento `memoriaTFG.pdf`, donde se explican los fundamentos teóricos y metodológicos del modelo desarrollado.

---

## 🖥️ Uso del repositorio

Este repositorio está diseñado como referencia para consultar el código empleado en el TFG. Todo el código se encuentra en un archivo `.qmd` (Quarto Markdown) que contiene bloques (chunks) en **R**, acompañados de explicaciones y resultados intermedios.

### Para revisar el código:
1. Abra el archivo principal `analisis_exploratorio.qmd`.
2. Ejecute los bloques de código en un entorno compatible con **Quarto** o **RStudio** para reproducir los análisis.

---

## 📂 Estructura del repositorio

- `analisis_exploratorio.qmd`: Archivo principal con el código y explicaciones en formato Quarto.
- `memoriaTFG.pdf`: Documento de la memoria completa del trabajo, que incluye los capítulos teóricos y la interpretación de los resultados.
- `causas_muerte.xls`: archivo con la base de datos utilizada en el análisis.
